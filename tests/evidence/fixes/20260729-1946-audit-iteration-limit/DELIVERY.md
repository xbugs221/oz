# 自动工作流不再无限自查

## 这次给用户带来了什么

新生成的工作流配置默认最多执行三轮全量自查。达到三轮后不再继续自查，而是直接进入独立测试；测试不通过时再针对实际失败进行修复。

## 如何验收

1. 在一个 Git 仓库运行 `oz flow config`。
2. 打开生成的配置，应看到默认自查上限为 3。
3. 运行 `oz flow graph --change demo --format mermaid`。
4. 应看到自查未达三轮时可以继续，达到三轮后直接进入独立测试。

## 修复前后对比

| 场景 | 修复前 | 修复后 |
|---|---|---|
| 新建工作流配置 | 没有自查轮次上限 | 默认最多三轮，可自行调整 |
| 查看工作流图 | 发现问题后持续自查 | 明确展示三轮触顶后进入独立测试 |

## 已知限制

已经启动的工作流继续使用启动时封存的旧配置；新上限用于之后创建的运行。
