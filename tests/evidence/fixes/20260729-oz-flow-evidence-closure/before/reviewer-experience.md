# 修复前：证据看似齐全，审核人员却无法验收

基准版本：`8fbc9bf`

## 用户场景

审核人员收到一个已归档提案，目录中存在 `final-demo.webm`，于是点击它查看提案能力。

## 实际结果

- 文件只有“final demo video”一行文字，并不是可播放视频。
- 归档仍被判定通过，因为旧门禁只检查文件存在、非空、扩展名和 Git 状态。
- 证据目录的说明主要是运行编号、阶段和哈希，审核人员看不到“如何按用户路径验收”。
- 修复前后即使内容相同，也没有提交级拦截。

## 对用户的影响

提案在流程上显示完成，但审核人员无法从提交中确认用户究竟获得了什么，也无法复现或演示交付能力。
