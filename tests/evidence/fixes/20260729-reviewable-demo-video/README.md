# 视频证据格式限制修复记录

## 原因

提案合同在内容检查前先按文件扩展名放行，只允许 WebM、MP4、MOV 和 MKV。该规则会拒绝真实、可播放但不在名单中的视频，也会让 WebM 示例被误解为固定要求。

## 修复

- 删除提案合同中的视频扩展名白名单。
- 归档检查只自动拒绝空文件、过小文件和纯文本伪装。
- 保留审核阶段实际打开视频、确认内容覆盖目标能力的要求。
- 用真实 AVI 样例覆盖不同格式的归档路径。

## 复核

- `go test ./internal/acceptance`
- 技能结构检查：项目内与全局 `oz-create`、`fix-code`、`fix-webapp` 均通过。
