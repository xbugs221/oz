# 演示视频不再被固定格式卡住

## 这次给用户带来了什么

- 可以直接使用录制工具实际产出的视频，不必为了归档额外转换成 WebM。
- 是否合格取决于审核人员能否打开并看懂，而不是文件后缀。
- 文字改后缀、空文件和过小文件仍会被拒绝。

## 如何验收

1. 准备一段审核人员可以直接播放的演示视频，例如 AVI。
2. 在提案中按视频的实际文件名声明临时位置和归档位置。
3. 执行提案检查，应不再出现“必须使用指定视频格式”的提示。
4. 归档后直接打开该视频，确认画面完整展示了用户操作和结果。
5. 再用一份文字文件冒充视频，应明确被拒绝。
