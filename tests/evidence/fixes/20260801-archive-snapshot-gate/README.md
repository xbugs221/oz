# 归档快照门禁误阻断修复

## 根因

归档阶段把源码差异快照作为二次门禁。归档移动提案或恢复后产生新源码版本时，旧审计的 validation diff 会被 QA 复用，导致可恢复任务被错误标记为停滞。

## 修复

- 归档仅校验最终独立 QA 和封存证据，不再比较源码快照。
- QA 遇到旧审计 validation diff 时，自动回到新的 audit 阶段。
- 恢复产生的新 audit 必须实际执行，不受普通 audit 轮次上限跳过。

## 验证

运行 `go test ./internal/app -count=1`，覆盖归档移动、QA diff 漂移和恢复重审。
