# 归档不会再因自身移动文件而停住

## 这次给用户带来了什么

已通过独立检查的任务在归档时，可以正常移动提案并同步引用，不会因这类预期文件变化被错误暂停。

## 如何验收

1. 让一个已完成独立检查的提案进入归档。
2. 等待归档完成文件移动和引用同步。
3. 查看任务状态。
4. 应看到任务继续完成或进入下一提案，而不是提示“validation diff 绑定不一致”。

## 修复前后对比

| 修复前 | 修复后 |
| --- | --- |
| 归档或恢复后的正常文件变化可能让任务停在可恢复暂停。 | 归档只确认最终检查与封存交付物，正常移动不会造成暂停。 |

## 已知限制

最终独立检查不完整、封存交付物缺失或未提交时，归档仍会停止，避免交付不完整结果。
