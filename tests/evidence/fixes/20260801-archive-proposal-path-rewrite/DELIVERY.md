# 归档不会因测试路径整理而中断

## 这次给用户带来了什么

完成最终验收后，归档可以把提案中的测试引用整理到归档目录，不会再因此把正常交付误报为失败。

## 如何验收

1. 完成一个带提案内测试文件的工作流并进入归档。
2. 归档时让测试引用随提案移动到日期归档目录。
3. 应看到归档继续完成，而不是提示最终验收后的内容发生变化。

## 修复前后对比

此前，只要归档整理了提案内的测试路径，流程就可能停止。现在仍会保护实现和最终证据，但允许归档整理提案包装内容。

## 可直接查看的证据

对应场景已由工作流回归测试覆盖：提案测试路径移动可完成归档；仓库源码被改动时仍会被拦截。

## 已知限制

最终验收合同和提交级证据仍会单独校验，归档不能借此改变它们。
